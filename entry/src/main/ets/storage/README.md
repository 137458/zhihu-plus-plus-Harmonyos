# storage/

会话和本地设置存储目录。

## 职责

- Cookie/Token 的安全保存和恢复
- 冷启动会话恢复
- 非敏感设置的持久化（主题、字号、过滤规则等）
- 存储版本迁移策略

## 设计约束

- 敏感数据（Token、Cookie）使用 `Asset Store Kit` 或安全存储，禁止放入普通 KV
- 非敏感设置使用 `preferences` 或 `PersistenceV2`
- 敏感数据不进入日志、源码、普通 KV 和测试样本
- 存储版本升级时必须有迁移测试，不破坏旧数据
- 退出登录时必须清理：凭据、Web Cookie、内存状态、路由状态
