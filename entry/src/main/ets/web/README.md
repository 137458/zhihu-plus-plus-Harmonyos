# web/

ArkWeb 容器目录。

## 职责

- ArkWeb 生命周期管理、可信域限制、正文加载和登录回调处理
- 加载经协议层转换后的 HTML 正文
- 应用深色模式和正文样式
- 展示公式、表格、图片和复杂嵌套内容
- 通过受控桥接向原生层报告必要事件

## 设计约束

- 只允许 HTTPS 和明确可信的主机列表
- 不允许正文内容直接执行不受控的原生方法
- 不把 Token、Cookie 或个人信息拼接到正文 HTML
- 外链跳转必须校验协议、主机和路径
- 登录回调必须校验完整落地 URL，不能只判断固定字符串片段
- ArkWeb 销毁后必须无残留监听器、定时器或页面引用
