# model/

领域模型目录（不依赖 ArkUI，便于单元测试和协议回放）。

## 职责

- 首页卡片、问题、回答、文章、作者、分页等显式 ArkTS 模型定义
- 协议响应解析后的数据结构
- 业务实体的纯数据表达，不混入 UI 状态

## 设计约束

- 所有模型使用显式 `class` / `interface` 定义，字段类型必须具体
- 禁止 `any` / `unknown` / `Record<string, string>` 等动态类型
- 不依赖 `@kit.ArkUI`，保证可在 TaskPool / Worker 中传递
- 跨线程传递的大对象考虑使用 `@Sendable`

## 后续批次规划

| 批次 | 内容 |
|---|---|
| 第 2 批 | 首页卡片、问题、回答、文章、作者、分页模型 |
| 第 3 批 | 详情页内容模型（问题详情、回答详情、文章详情） |
| 第 5 批 | 评论、个人页内容模型 |
